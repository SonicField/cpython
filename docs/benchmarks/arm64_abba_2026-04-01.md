## Regression Analysis

1. **gen_simple -25%:** Generator resume path has JIT infrastructure overhead (deopt trampoline).
2. **nn_module_forward -16%:** Very short-running benchmark dominated by JIT function call overhead.
3. **gen_nested -11%:** Same generator overhead as gen_simple, compounded by nesting.
4. **decorator_chain -8%:** Decorator wrapping adds JIT entry/exit overhead per layer.
5. **try_except_callee -7%:** Exception handling path less optimized in JIT.
6. **kwargs_dispatch -6%:** Keyword argument unpacking overhead in JIT calling convention.
