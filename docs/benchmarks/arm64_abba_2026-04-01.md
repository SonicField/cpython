## Regression Analysis

1. **gen_simple -24%:** Generator resume path has JIT infrastructure overhead (deopt trampoline).
2. **nn_module_forward -14%:** Very short-running benchmark dominated by JIT function call overhead.
3. **gen_nested -11%:** Same generator overhead as gen_simple, compounded by nesting.
4. **try_except_callee -9%:** Exception handling path less optimized in JIT.
5. **decorator_chain -6%:** Decorator wrapping adds JIT entry/exit overhead per layer.
6. **func_calls -5%:** At the boundary of significance, JIT calling convention overhead.
