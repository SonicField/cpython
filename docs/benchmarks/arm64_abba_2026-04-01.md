## Known Issues

1. **nbody crashes** under JIT on ARM64. All JIT_ON subprocess runs exit with code 1. Vanilla runs succeed (~38ms). Separate bug from float codegen — involves list mutation with computed float values.
2. **gen_simple -27%:** Generator resume path has JIT infrastructure overhead.
3. **nn_module_forward -17%:** Short-running benchmark dominated by JIT startup overhead.

## Float Fix Impact

The PHX_FP_FLAG fix (ec748db5de) corrected ARM64 FP register encoding:
- `a64::d()` was missing PHX_FP_FLAG (0x40), causing all FP registers to be treated as GP
- This caused fmov direction reversal, V-bit errors in ldr/str, and wrong float arithmetic results
- float_arith went from 1.00x (wrong answer: -0.0) to 0.99x (correct answer: 2469.7)
- Overall 1.32x speedup UNCHANGED — integer benchmarks (fibonacci, richards, nqueens) dominate
